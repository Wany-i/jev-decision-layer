## 结论摘要（≤10 行）

1. **确认可用的一手直连通道**：TypeSafe 官方 HTTP `POST https://api.typesafe.ai/v1/systemone`（Bearer），但**需 waitlist 审核**取得 key。
2. **确认可用的第三方网关**（4 家官方页面可直接佐证）：OpenRouter（`/api/alpha/decisions`）、Vercel AI Gateway（`typesafe-ai/jev`）、Cloudflare AI / Workers AI（`typesafe/jev`）、Netlify AI Gateway（`@typesafe-ai/sdk` 零配置）。
3. **OpenRouter 三语言官方 SDK 齐全**：TypeScript `@openrouter/sdk`、Python `openrouter`、Go `github.com/OpenRouterTeam/go-sdk`，均走 `alpha.decisions.create`。
4. **AI SDK 原生集成**：Vercel AI SDK 7.0.105+ 的 `experimental_evaluate`，另有官方 provider 包 `@ai-sdk/typesafe-ai`。
5. **可观测/评测平台**：Braintrust 已原生适配（`wrapTypeSafe()` + judge scorer）；Langfuse / Arize(Phoenix) **未找到**针对 Jev 的专属适配，仅有通用 OTel/OpenInference 路径。
6. **聚合网关负面结论**：Portkey、Requesty、LiteLLM、Helicone、Together、Fireworks、Groq —— 用多种关键词组合检索**均未命中**其已上架该模型。
7. 额外发现第三方聚合站 **AnyRouter** 列出 `typesafe/jev-latest`，但**只支持 BYOK（自带 TypeSafe key）**，非其自有额度通道。
8. **Access 前提**：TypeSafe 直连需候补；Vercel/Netlify/Cloudflare/OpenRouter 走各自账号账单，**无需 TypeSafe key**（Azure/Netlify 免 key；Cloudflare/OpenRouter 走各自 credits）。
9. **`typesafe/jev-1.13:free` 变体：未找到**——该模型是原生低价（输入 $0.042/M、输出 $0）而非 `:free` 免费档模型。
10. 全通道**仅支持文本**输入（string / JSON object / text array），无视觉、无 chat/completions 协议。

## 逐条发现

### 1. TypeSafe 直连 HTTP —— 唯一一手端点，需候补 `[官方]`

- 结论：官方唯一评估端点 `POST https://api.typesafe.ai/v1/systemone`，Bearer 鉴权，请求体顶层 `model` / `state` / `questions`。
- 证据原文摘录（docs.typesafe.ai/introduction/quickstart）：
  > `POST https://api.typesafe.ai/v1/systemone`
  > `Authorization: Bearer <API_KEY>`
  > `Content-Type: application/json`
  > 1. **Get your API key** from the dashboard（`https://console.typesafe.ai/settings/keys`）
- 模型与限流（docs.typesafe.ai/models，`[官方]`）：
  > Jev 1.13 `jev-1.13.0`　Price (per Btok / per Mtok) **$42 / $0.042**　Rate limits **250,000 tokens per second / 1,200 requests per minute**　Context length **64k tokens per request; 32k tokens for state plus the longest question**　Input **Text only.**
- 别名（docs.typesafe.ai/models，`[官方]`）：
  > `jev-latest` → `jev-1.13.0`（most recent stable release，SDK 默认值）
  > `jev-preview` → `jev-1.13.0`（当前无 preview 构建）
- 也有 `GET /v1/models`（`[官方]`）："returns the names your account can send in the `model` field"。
- 错误码（`[二手转述]` flaviocopes.com/jev，抓取 2026-09-18）：401 缺/错 key；422 请求体校验失败；429 限流；529 服务过载。
- **前提条件**：候补（waitlist）。官网 `typesafe.ai` 申请 → 通过后 `console.typesafe.ai` 取 key（`[二手转述]` 多个指南一致，见下）。
  > "Jev is in early access. You join the waitlist at typesafe.ai and get an email when you're in. From what people reported in the first days, access came within a day or two of signing up."（worldprogramming.org，`[二手转述]`）
  > "目前处于早期访问阶段，需要通过候补名单获取调用权限……官方未公布免费额度或试用积分方案"（aihub.cn，`[二手转述]`）

### 2. OpenRouter Decisions —— 无需 TypeSafe key，付费 credits `[官方]`

- 结论：OpenRouter 侧调用**不套 `input`**，body 顶层即 `model`/`state`/`questions`；端点为 `POST https://openrouter.ai/api/alpha/decisions`（主 agent 已实测确认，本代理不重复验证）。
- 模型页原文摘录（openrouter.ai/typesafe/jev-1.13，`[官方]`，抓取 2026-09-19）：
  > In / Out Price **$0.042 / $0** per 1M　Context **32K**　Released **Sep 18, 2026**　Providers：TypeSafe（**This model is hosted by one provider**）
  > `POST https://openrouter.ai/api/alpha/decisions`　`Authorization: Bearer $OPENROUTER_API_KEY`
  > Model `typesafe/jev-1.13`
- 另一个 slug：`typesafe/jev-latest`（"This model always redirects to the latest model in the Jev family"，openrouter.ai/models，`[官方]`）。
- `~` 前缀写法：第三方实测文章使用 `~typesafe/jev-latest`（`[二手转述]` wpnews.pro，抓取 2026-09-18）；OpenRouter 通用规则中 `~author/model-latest` 表示"总是解析到该家族最新版本"（`[官方]` openrouter.ai/blog/tutorials/any-coding-agent）。
- **`:free` 支持**：OpenRouter 模型页未出现 `:free` 变体或 `$0` 输入价；免费档机制是"ID 结尾 `:free`"，仅适用于免费模型变体（`[官方]` openrouter.ai/docs/limits）。因此 **`typesafe/jev-1.13:free` 未找到**。
- 限流/计费规则（`[官方]` openrouter.ai/docs/limits，通用规则）：
  > If you're using a free model variant (with an ID ending in `:free`) … up to 20 requests per minute … if you have purchased less than 10 credits, you're limited to 50 `:free` model requests per day；≥10 credits → 1000/day
  > 付费模型无平台级请求上限；credit 购买收 5.5% 手续费（最低 $0.80）（`[二手转述]` pinggy.io / checkthat.ai）
- 官方博客确认上架（`[官方/二手]`）：OpenRouter X 帖称 "$0.042 per million input tokens, output tokens free"、"takes your app's state plus a typed question and returns a typed decision with a probability attached"（转引自 huggingnews.com，`[二手转述]`）。

### 3. OpenRouter 三语言官方 SDK `[官方]`

- 三个 README 均属 `Alpha.Decisions`（"Alpha feature endpoints for Decisions (questions and answers) requests"），可用操作只有 `create`（"Submits a Decisions request to the Decisions router"）。
- ES：`[一手代码]`（README 代码原样）。
- 参数表（TypeScript README，`[官方]`）：`request`（`operations.CreateApiAlphaDecisionsRequest`，必填）；可选 `httpReferer` / `appTitle` / `appCategories` / `provider` / `session_id` / `trace` / `user`。

### 4. Vercel AI Gateway —— AI SDK 原生 `experimental_evaluate` `[官方]`

- 结论：Jev 作为 **evaluation model** 上架，模型 id `typesafe-ai/jev`（带连字符 `typesafe-ai`，与 OpenRouter/TypeSafe 的 `typesafe` 命名不同）。
- changelog 原文摘录（vercel.com/changelog/typesafe-ai-jev-now-available-on-ai-gateway，`[官方]`）：
  > "AI SDK 7 exposes Jev through the experimental evaluate API."
  > "Install the current AI SDK (AI SDK 7.0.105 onwards supports the evaluate API): `pnpm add ai@latest`"
  > "Call the model with `typesafe-ai/jev`."
  > "TypeSafe reports separate Choice and Score confidence in `result.providerMetadata.typesafe.confidence`."
  > "Jev supports Zero Data Retention and No Training, enabled per request"（`providerOptions.gateway.zeroDataRetention`，Vercel Pro/Enterprise 可用）
- 模型页（vercel 模型目录，`[官方/二手]`）：Input **$0.04/M**，Release Date **09/15/2026**，Provider **TypeSafe AI**；仅 1 个 provider。
- 关键约束（`[官方]` developer.vercel.com/docs/ai-gateway/modalities/evaluation）：
  > "Evaluation is available through the AI SDK only. It is not supported through the OpenAI-compatible, Anthropic-compatible, or Cohere-compatible endpoints."
  > 题型的 yes/no 在 AI SDK 里叫 `boolean`，答案字段是 `probability`（Choice/Score 保留原名）。
- 直连 provider 包（`[二手转述]`，引自官方文档）：`npm install ai @ai-sdk/typesafe-ai`，`typeSafeAi.evaluationModel('jev-latest')`，环境变量 `TYPESAFE_AI_API_KEY`，**Node.js ≥ 22**。

### 片段 A（Python）— TypeSafe 官方 HTTP 直连 `[官方]`
出处：https://docs.typesafe.ai/introduction/quickstart（抓取 2026-09-19）

```bash
curl -X POST https://api.typesafe.ai/v1/systemone \
  -H "Authorization: Bearer $TYPESAFE_API_KEY" \
  -H "Content-Type: application/json" \
  -d @- <<'EOF'
  {
    "state": "Hi, I've been trying to connect my Stripe account for 3 days and it keeps failing. I'm losing sales. Please help ASAP.",
    "model": "jev-latest",
    "questions": {
      "urgency": {
        "type": "noul",
        "instructions": "Does this message express urgency?"
      }
    }
  }
EOF
```

Python SDK（同页，`[官方]`）：
```python
from typesafe_sdk import Choice, Noul, Score, TypeSafeClient

client = TypeSafeClient()

ticket = "Hi, I've been trying to connect my Stripe account for 3 days and it keeps failing. I'm losing sales. Please help ASAP."

response = client.system_one(
    state=ticket,
    questions={
        "department": Choice(
            instructions="Which team should handle this",
            criteria={
                "billing": "Payment or subscription issues",
                "technical": "Bugs or integration problems",
                "sales": "Pricing or account questions",
            },
        ),
        "frustration": Score(
            instructions="How frustrated the customer appears",
            criteria=[
                "Calm, just stating facts",
                "Frustrated but civil",
                "Very angry, strong language",
            ],
        ),
        "is_urgent": Noul(
            instructions="The message conveys urgency or time-sensitivity",
        ),
    },
)

print(response.answers["department"].choice)  # "billing"
print(response.answers["frustration"].score)  # 1.035
print(response.answers["is_urgent"].noul)     # 0.999
```

## 存疑与未证实

1. **AnyRouter 的上下文口径**：其页面标 128K context，与官方 64K/32K 不符；且标注 BYOK，可信度低，未独立复现。
2. **TypeSafe 直连是否一定需要候补**：多个二手指南一致称需 waitlist，但**未找到官方页面在 2026-09-19 明确写"必须候补"**；官方 quickstart 只写"Get your API key from the dashboard"。候补结论标 `[二手转述]`。
3. **`typesafe/jev-1.13:free`**：OpenRouter 模型页为 $0.042/$0 定价，未出现 `:free` 变体；"不支持 / 不存在"仍以"未找到"为准。
4. **OpenRouter 上架日期**：模型页写 "Released Sep 18, 2026"，而 Vercel 模型页写 "09/15/2026"，TypeSafe 发布日为 2026-09-15。差异应为"OpenRouter 上架日" vs "模型发布日"，但**不确定**，标 `[推测]`。
5. **Portkey/Requesty/LiteLLM 是否支持**：未命中≠不支持；这些网关可能通过"自定义 OpenAI-compatible endpoint"间接转发，但 Jev 是 Decision 协议（非 chat/completions），**理论上无法直接套用**，此推论标 `[推测]`。
6. **Braintrust native judge 的具体开通流程**：官方仅写 "You'll need to request access"，未给 URL/表单。
7. **各家 SDK 版本语义**：TypeSafe JS SDK 生态里同时出现 `@typesafe-ai/sdk`（Netlify）与 `@ai-sdk/typesafe-ai`（Vercel provider），二者**不是同一个包**；已在对照表中分开标注。
8. **未验证项**：我未实际发请求测试任何端点（主 agent 已实测 OpenRouter），所有端点为文档/官网原文转载。
