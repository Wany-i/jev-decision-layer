### C. 设计原则类页面（confidence / jaggedness / patterns）

**C1. `confidence` 的官方定义**
- 原文（关键段）："All Score and Choice answers from TypeSafe include a `probabilities` property… The *shape* of that distribution is what tells you how certain the model is: concentrated on one outcome means a confident answer, spread out means an uncertain one. The answer's `confidence` property **collapses that shape into a single number from 0 to 1**… (**Noul answers don't carry one.**)"
- 原文（可替换性）："we provide `confidence` as a convenient measure… but **you are never locked into our definition**… which is exactly why we give you the full `probabilities`."
- 原文（三档用法）：High = act automatically；Medium = proceed with caution；Low = do not act, route to human。并强调 "A confidence threshold is not one number… Different actions within the same system should be gated at different levels."
- 来源类型：`[官方]`
- URL：https://docs.typesafe.ai/confidence.md ｜抓取：2026-09-19

**C2. `Jev 1.13 jaggedness` 页——官方自曝 9 类失败模式**
- 原文："`jev-1.13` is fast, calibrated, and good at common-sense judgment but it is not perfect… It may struggle with tasks that require additional levels of indirection. It can be quite literal in its understanding. **It struggles with tasks that require numeric precision.**"
- 官方列出的 9 条失败模式（带"应该怎么做"列）：
  1. Literal reading（字面理解）
  2. Math and Numbers（不做计算/不计数，计数应放代码）
  3. Date and time comparison（日期当文本读，不当作序数量）
  4. Indirection（多跳推理掉准）
  5. Large state full of irrelevant detail（"Jev suffers from **context rot**"）
  6. Adversarial content（state 中的注入/误导可改变答案）
  7. Contradictory instructions and criteria
  8. Common-sense structural invariants（**不保证结构不变量**）
  9. Generation（不是文本生成模型，链式 choice 硬凑很慢很差）
- 来源类型：`[官方]`
- URL：https://docs.typesafe.ai/model-jaggedness/jev-1.13.md ｜抓取：2026-09-19
- 页内元信息：`Applies to jev-1.13`，**Last reviewed 2026-09-17**。

```python
def route_ticket(ticket_id, response):
    intent = response.answers["intent"]
    complexity = response.answers["complexity"]

    if intent.confidence < 0.5:
        # If we don't have enough confidence to classify, route to a human agent
        return route_to_human_agent(ticket_id)

    if intent.choice == "order_status":
        handle_order_status(ticket_id)

    elif intent.choice == "product_question":
        handle_with_llm(ticket_id, PRODUCT_SPECIALIST)

    elif intent.choice == "return_exchange":
        handle_with_llm(ticket_id, RETURNS_SPECIALIST)

    elif intent.choice == "complaint":
        low_confidence = complexity.confidence < 0.5
        # A higher complexity.score leans toward the "escalation needed" end of the scale.
        if complexity.score > 1 or low_confidence:
            # Too complex for safe automation, or we're not sure about the complexity; route to a human.
            route_to_human_agent(ticket_id)
        else:
            handle_with_llm(ticket_id, COMPLAINT_RESOLUTION)
```

## 存疑与未证实

1. **`id` 与 `provider` 字段来源不明**。主 agent 实测响应含 `id` / `provider`，官方 HTTP API 参考只定义 `model` / `answers` / `usage`。推测为 OpenRouter 代理层附加字段。`[推测]`——建议在报告里标注"官方未定义，代理层附加"。
