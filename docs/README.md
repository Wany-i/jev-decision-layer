## 这些文档是什么

调研对象是 `typesafe/jev-1.13` —— TypeSafe AI 于 2026-09-15 发布的 "System One" **决策模型**
（输入 `state` + 声明式 `questions`，输出类型化答案 + 概率 + 置信度，**不生成文本**）。
本仓库的代码就是基于这批调研写出来的。

**方法与时间**：2026-09-19 一天内完成。分四步：

1. **六路并行检索**不同信源（官方文档 / 网关通道 / GitHub / 社交平台与论坛 / 视频与中文社区 / 生态集成）
2. **一手实测**：对接口本身做调用验证（端点、请求体形状、上下文边界、成本、中文表现、置信度对 state 规模的敏感性）
3. **第四方独立复核**：复核方未参与调研，只负责找错，抽验 35 条断言
4. **按复核结论定稿**：被证伪的整段撤下，口径不准的改口径，无法复验的降级标注
